Mettre en place son environnement

Notions fondamentales

Python en quelques mots

  • Interprété : pas de compilation, on exécute directement le code
  • Multiplateforme : Windows, macOS, Linux
  • Lisible : l'indentation fait partie de la syntaxe
  • Riche : une bibliothèque standard fournie et des centaines de milliers de paquets sur PyPI

Créé par Guido van Rossum (première version en 1991), son nom est un clin d'œil aux Monty Python.

Python 2 ou Python 3 ?

Python 2 n'est plus maintenu depuis le 1er janvier 2020. Pourtant, beaucoup de vieux scripts d'exploit sont encore écrits en Python 2 : il faut savoir les reconnaître et les adapter.


print "pwned"    # Python 2
print("pwned")   # Python 3
Nous utilisons exclusivement Python 3. Le cas Python 2 reviendra en audit technique et en reverse.

Installer Python

Installez Python 3.12 au minimum, idéalement la dernière version stable.

Windows

  • Installateur de python.org
  • Cochez « Add python.exe to PATH »
  • Vérifiez : py --version
  • ⚠ Si python ouvre le Microsoft Store : Paramètres → Applications → Alias d'exécution d'applications → désactivez python.exe

macOS

  • Installateur de python.org ou brew install python
  • Vérifiez : python3 --version
  • ⚠ Le python3 fourni avec les outils Xcode est trop ancien (3.9) : vérifiez toujours la version

Linux

  • sudo apt install python3 python3-venv python3-pip
  • Vérifiez : python3 --version
  • ⚠ Sous Debian et Ubuntu, venv est un paquet séparé
  • Kali : Python 3 est déjà installé
Première heure : je fais le tour des postes. Les confirmés aident leurs voisins. Sous Windows, le lanceur py est installé avec Python ; python fonctionne aussi une fois le PATH configuré.

Dans VS Code : installez l'extension Python, puis Ctrl+Maj+P → Python: Select Interpreter → choisissez celui du dossier .venv. Exécutez avec le bouton ▶ ou dans le terminal intégré.

Pourquoi un environnement virtuel ?

  • Sans venv, tous les paquets s'installent au même endroit : deux projets qui exigent deux versions d'une même bibliothèque entrent en conflit
  • Un venv est un dossier .venv propre au projet, avec son Python et ses paquets
  • Aucun droit administrateur nécessaire
  • Reproductible : la liste des paquets tient dans un fichier

Côté cyber

Chaque outil (Impacket, pwntools…) dans son propre venv : pas de conflit et vous savez exactement ce qui est installé.

Attention au typosquatting

Des paquets malveillants imitent des noms connus à une lettre près (reqeusts au lieu de requests). Vérifiez toujours le nom exact sur PyPI avant d'installer.

Le typosquatting est une attaque réelle de la chaîne d'approvisionnement : on en reparlera en DevSecOps.

Variables et types

Notions fondamentales

Les variables

Une variable est une boîte étiquetée : le nom est l'étiquette, la valeur est le contenu. On la crée avec =.


username = "alice"
failed_attempts = 0
MAX_ATTEMPTS = 3        # constante : majuscules

failed_attempts = failed_attempts + 1
print(username, failed_attempts)   # alice 1

Règles de nommage (PEP 8)

  • snake_case : failed_attempts
  • En anglais, sans accent, explicite : failed_attempts plutôt que fa
  • Sensible à la casse : user et User sont deux variables différentes
  • Constantes en MAJUSCULES : MAX_ATTEMPTS

Les types de base


port = 443                # int
cvss_score = 9.8          # float
hostname = "srv-web-01"   # str
is_admin = False          # bool
last_login = None         # aucune valeur

print(type(port))         # <class 'int'>
print(type(cvss_score))   # <class 'float'>
print(type(last_login))   # <class 'NoneType'>

Python devine le type tout seul (typage dynamique) ; type() permet de le vérifier. Les octets (bytes) viendront au cours 3.

Conversions, saisie et affichage


port = input("Port : ")     # on tape 8080
print(type(port))           # <class 'str'>

port = int(port)            # conversion en int
print(port + 1)             # 8081

score = float("7.5")        # 7.5
label = str(443)            # "443"
print("Port " + label)      # Port 443
input() renvoie toujours une chaîne, même si l'utilisateur tape un nombre. Pour calculer, il faut convertir avec int() ou float().
  • print() affiche une ou plusieurs valeurs, séparées par des espaces
  • int("https") provoque une erreur ValueError : on verra comment la gérer en partie #7

Chaînes : indices et découpage

192.168.1.42

ip = "192.168.1.42"

print(ip[0])       # 1
print(ip[-1])      # 2
print(ip[0:7])     # 192.168

  • s[début:fin] : la fin est exclue ; début omis = depuis le début, fin omise = jusqu'au bout
  • Une chaîne ne se modifie pas : ip[0] = "2" provoque une erreur

Exemple tiré d'un vrai journal SSH (/var/log/auth.log). Le découpage de ligne resservira dans le défi 2.

Notions fondamentales

Les opérateurs


print(17 + 5, 17 - 5, 17 * 5)   # 22 12 85
print(17 / 5)    # 3.4   division
print(17 // 5)   # 3     division entière
print(17 % 5)    # 2     reste (modulo)
print(2 ** 10)   # 1024  puissance

port = 8080
print(port == 443, port != 443, port > 1024)
# False True True
ComparaisonSignification
== / !=égal / différent
< / <=inférieur / ou égal
> / >=supérieur / ou égal
% (modulo) est au cœur de la cryptographie : chiffre de César, Diffie-Hellman, RSA. Vous le retrouverez en Cryptologie.

Ne pas confondre : = affecte une valeur, == compare deux valeurs.

if, elif, else


role = "analyst"
failed_attempts = 1

if failed_attempts >= 3:
    print("Compte verrouillé")
elif role == "admin":
    print("Accès total")
elif role == "analyst":
    print("Accès en lecture")    # ← exécuté
else:
    print("Accès refusé")
  • Les conditions sont testées dans l'ordre : seul le premier bloc dont la condition est vraie s'exécute
  • elif et else sont facultatifs
  • Les deux-points : ouvrent un bloc ; l'indentation (4 espaces) délimite ce bloc
  • Une erreur d'indentation change le sens du programme, voire l'empêche de s'exécuter

match / case


command = "scan"

match command:
    case "scan":
        print("Lancement du scan…")    # ← exécuté
    case "report" | "export":
        print("Génération du rapport")
    case "quit":
        print("Au revoir")
    case _:

  • | signifie « ou »
  • _ est le cas par défaut
  • Disponible depuis Python 3.10

Notions fondamentales

Les listes


open_ports = [443, 22, 80]

print(open_ports[0])        # 443
open_ports.append(3306)     # ajoute à la fin
open_ports.remove(80)       # retire la valeur 80
open_ports.sort()           # trie sur place
print(open_ports)           # [22, 443, 3306]

print(22 in open_ports)     # True

  • Une collection ordonnée et modifiable, entre crochets []
  • Indices et découpage fonctionnent comme pour les chaînes : logs[-10:] donne les 10 dernières lignes
  • remove() retire la première occurrence trouvée
  • Toutes les méthodes : documentation officielle

Tuples et ensembles


# Tuple : non modifiable
target = ("10.0.0.5", 22)
ip, port = target          # déballage
print(f"{ip}:{port}")      # 10.0.0.5:22

# Ensemble : valeurs uniques, sans ordre
ips = ["10.0.0.5", "10.0.0.9", "10.0.0.5"]
unique_ips = set(ips)
print(len(unique_ips))     # 2
unique_ips.add("10.0.0.12")
print("10.0.0.9" in unique_ips)    # True

Tuple ( )

Ordonné, non modifiable : parfait pour une valeur composée qui ne doit pas changer (adresse et port)

Ensemble set

Sans doublon et sans ordre : parfait pour dédupliquer les IP d'un journal

La boucle for


open_ports = [22, 80, 443]
for port in open_ports:
    print(f"Port {port} ouvert")

for i in range(1, 4):     # 1, 2, 3

  • for parcourt chaque élément d'une séquence : liste, chaîne, tuple, ensemble, dictionnaire
  • range(début, fin) produit une suite d'entiers, fin exclue ; enumerate() numérote les éléments ; .items() donne clé et valeur

while, break, continue


SECRET = "S3cur3!"
attempts = 0

while True:
    password = input("Mot de passe : ")
    attempts += 1          # attempts = attempts + 1
    if password == SECRET:
        print("Accès autorisé")
        break              # sortie immédiate
    if attempts == 3:
        print("Compte verrouillé")
        break
  • while condition: répète tant que la condition est vraie
  • while True: tourne indéfiniment : on en sort avec break (c'est le menu du TP1)
  • continue passe directement au tour suivant

for port in [21, 22, 80]:
    if port == 21:
        continue  # saute FTP
    print(port)   # 22 puis 80
Un mot de passe en clair dans le code est bien sûr une mauvaise pratique : on verra le stockage par hash au cours 3.

Compter avec un dictionnaire


log = [
    "Failed password for root from 10.0.0.5",
    "Accepted password for alice from 10.0.0.9",
    "Failed password for admin from 10.0.0.5",
]
failures = {}
for line in log:
    if line.startswith("Failed"):
        ip = line.split(" ")[-1]
        failures[ip] = failures.get(ip, 0) + 1
print(failures)        # {'10.0.0.5': 2}
  • failures.get(ip, 0) renvoie le compteur actuel ou 0 si l'IP est nouvelle
  • On ajoute 1 et on enregistre le résultat sous la même clé
C'est le principe de la détection de brute force utilisée par fail2ban ou un SIEM : compter les échecs par source, puis alerter au-delà d'un seuil. Vous l'appliquerez dans le défi 2.

Qu'affiche ce programme ?


ports = [21, 22, 80, 443, 8080]
count = 0
for port in ports:
    if port < 80:
        continue
    if port == 443:
        break
    count += 1
print(count)

total = 0
for i in range(3):
    total += i
print(total)
1 : 21 et 22 sont sautés par continue, 80 est compté, puis la boucle s'arrête sur 443 : 8080 n'est jamais atteint
3 : range(3) produit 0, 1 et 2, donc 0 + 1 + 2 = 3
Réponses : 1 puis 3. Pièges : break interrompt toute la boucle (8080 jamais vu) ; range(3) commence à 0 et exclut 3.

Fonctions et modules

Notions fondamentales

Définir une fonction


def is_valid_port(port):
    """Vrai si port est un port TCP valide."""
    return 0 <= port <= 65535

def format_alert(ip, level="INFO"):
    return f"[{level}] Activité suspecte : {ip}"

print(is_valid_port(8080))          # True
print(is_valid_port(70000))         # False
print(format_alert("10.0.0.5"))     # [INFO] …
print(format_alert("10.0.0.5", level="HIGH"))
# [HIGH] Activité suspecte : 10.0.0.5
  • def nom(paramètres): définit un bloc réutilisable
  • return renvoie un résultat et termine la fonction
  • La docstring ("""…""") documente la fonction
  • level="INFO" : valeur par défaut, utilisée si l'argument est omis
  • Nommez vos fonctions avec un verbe : une fonction, une tâche

Portée et retours multiples


def parse_login(line):
    words = line.split(" ")         # variable locale
    return words[3], words[-1]      # renvoie un tuple

user, ip = parse_login("Failed password for root from 10.0.0.5")
print(user, ip)                     # root 10.0.0.5
print(words)                        # erreur !
      

NameError: name 'words' is not defined
  • Une variable créée dans une fonction est locale : elle disparaît à la sortie
  • Pour renvoyer plusieurs valeurs, on renvoie un tuple, puis on le déballe

Importer un module


"""Utilitaires de sécurité."""

def is_valid_port(port):
    return 0 <= port <= 65535

if __name__ == "__main__":
    # si on exécute ce fichier directement
    print(is_valid_port(443))


import security
from security import is_valid_port

print(security.is_valid_port(22))  # True
print(is_valid_port(-1))           # False
  • Tout fichier .py est un module importable depuis un fichier du même dossier : c'est ce que fera votre main.py avec crew.py dans le TP1
  • if __name__ == "__main__": contient le code exécuté seulement quand on lance le fichier directement, pas quand on l'importe

try, except, else, raise


def ask_port():
    while True:
        try:
            port = int(input("Port : "))
        except ValueError:
            print("Entrez un nombre entier.")
        else:
            if 0 <= port <= 65535:
                return port
            raise ValueError("port hors limites")

print(f"Scan du port {ask_port()}")
  • try : le code qui peut échouer
  • except ValueError : ce qu'on fait si cette erreur précise survient ; le programme ne plante plus
  • else : exécuté seulement si aucune erreur n'a eu lieu
  • raise : lever soi-même une erreur quand une valeur est inacceptable
  • Ce schéma rend le menu du TP1 robuste aux saisies invalides

Les exceptions, côté sécurité

✗ À éviter


try:
    port = int(user_input)
except:
    pass     # erreur effacée sans trace

✓ À préférer


try:
    port = int(user_input)
except ValueError:
    print("Port invalide.")  # sobre
  • Un except: pass masque les anomalies, y compris une tentative d'attaque : on attrape toujours une erreur précise
  • N'affichez jamais un traceback complet à l'utilisateur : chemins, versions et noms de fichiers sont une fuite d'informations précieuse pour un attaquant
  • Le détail de l'erreur se consigne dans un journal, côté serveur : on verra comment au cours 3
