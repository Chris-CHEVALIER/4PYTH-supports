Objectif : montrer une méthode, pas seulement une solution. Un volontaire qui a réussi le défi tape le code ; la classe propose chaque étape à l'oral, je guide et je questionne. Environ 40 minutes.

La méthode en 4 étapes

1. Comprendre

Qu'est-ce qui entre dans la fonction ? Qu'est-ce qui en sort ? Que donnent les exemples de l'énoncé ?

2. Découper

Écrire les étapes en français, une par ligne, avant de taper la moindre ligne de code : c'est le pseudo-code.

3. Coder petit à petit

Une étape du plan à la fois. Le programme doit tourner après chaque ajout, même s'il ne fait pas encore tout.

4. Tester tout de suite

Relancer avec les exemples de l'énoncé après chaque étape. Une erreur trouvée tôt est une erreur facile à corriger.
Insister : la plupart des blocages d'hier venaient du passage de l'énoncé au code, pas de la syntaxe (le Kahoot était bon).

print(check_password("azerty"))   # (True, [])
  • La fonction tourne déjà : elle accepte tout, mais elle renvoie le bon type de résultat
  • len(errors) == 0 vaut True quand la liste est vide
  • return a, b renvoie un tuple

Étape 3b – La longueur


MIN_LENGTH = 12
ADMIN_MIN_LENGTH = 16

def check_password(password, is_admin=False):
    errors = []

    if is_admin:
        min_length = ADMIN_MIN_LENGTH
    else:
        min_length = MIN_LENGTH
    if len(password) < min_length:
        errors.append(f"au moins {min_length} caractères")

    return len(errors) == 0, errors
  • Les seuils sont des constantes en majuscules : on les modifie à un seul endroit
  • Test : check_password("azerty") renvoie maintenant (False, ['au moins 12 caractères'])

Étape 3c – Regarder chaque caractère


    has_upper = False
    has_lower = False
    has_digit = False
    has_special = False
    for char in password:
        if char.isupper():
            has_upper = True
        elif char.islower():
            has_lower = True
        elif char.isdigit():
            has_digit = True
        elif not char.isalnum():
            has_special = True
  • Quatre drapeaux (des booléens) partent à False : « je n'ai encore rien vu »
  • La boucle les passe à True dès qu'elle rencontre la catégorie
  • isalnum() est vrai pour une lettre ou un chiffre : not char.isalnum() repère donc un caractère spécial
Piège fréquent d'hier : vouloir tout décider dans la boucle. On observe d'abord (drapeaux), on conclut ensuite.

Étape 4 – Tester avec les exemples


print(check_password("Tr0ub4dour&Co"))

print(check_password("Azerty123456!"))

# (False, ['au moins 12 caractères', 'au moins une majuscule', 'au moins un chiffre',

Si un résultat diffère, on relit l'étape correspondante du plan : c'est là que se trouve l'erreur.
